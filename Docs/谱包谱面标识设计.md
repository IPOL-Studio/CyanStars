## 设计目标和条件

- 为谱包和谱面设计唯一的标识，以便对应展示成绩
- 兼容谱面结构升级
- 防呆，不防篡改

## 具体实现

在谱包元数据中，为谱面新增 UID。

在谱包元数据的谱面 List 字段中，为每个谱面新增 UID。

启动游戏时扫描所有的谱包，若存在相同的谱包 UID，将对应的两个（或多个）谱包记为冲突。不在游戏选曲页加载冲突的谱包。

逐谱包扫描其中的谱面 UID，若同一谱包中存在相同的谱面 UID，将谱包标记为冲突。不在游戏选曲页加载冲突的谱包。

谱包管理 UI（进入制谱器前的弹窗）中高亮提示冲突的谱包，提示玩家自行修复。后续谱面损坏等情况也在此提示。

不同谱包之间的谱面 UID 可重复。

通过游戏内 UI 复制谱包和谱面时，新的谱面自动生成新的 UID。

游戏生成 UID 采用 UUID 算法，支持玩家修改后的任意 string 字段。

拼接 谱包-谱面 UID，作为成绩保存和索引依据。
